# ADR-0022: Pixel-Art Character Sprites

## Status

Accepted

## Date

2026-09-25

## Decision Makers

Kusuma Putra (solo dev) + Claude Code Game Studios

## Summary

Fayde and every enemy now use pixel-art sprite sheets instead of the capsule
placeholder. The user chose pixel art over the art bible's HD-2D illustrated
pipeline because it costs far less to make while still following the mood and
design rules. The sheets are generated by a script checked into the repo, so every
design can be edited and re-run. They can also be painted over by hand in Aseprite.

## Engine Compatibility

| Field | Value |
|-------|-------|
| **Engine** | Godot 4.6 |
| **Domain** | Rendering (2D) / Characters |
| **Knowledge Risk** | LOW: `Sprite2D` hframes/vframes/frame/flip_h, `texture_filter`, `Image` drawing and `save_png` are unchanged since 4.0 |

## ADR Dependencies

- ADR-0001 (isometric view): feet stay on the node origin; draw order is unchanged.
- ADR-0021 (procedural environment look): sprites use the same 1:1 pixel density
  as the 64×32 floor tiles.

## Context

All characters were drawn by `debug_circle_2d.gd` as a coloured rectangle with a
circle on top. The art bible §10 planned 128×256 illustrated sprites in 8 directions
made with Midjourney, which comes to about 120 images for Fayde alone. The user asked
for something cheaper that still matches the mood and design.

## Decision

1. **Generator** (`tools/art-gen/generate_character_sprites.gd` with
   `pixel_painter.gd`), run with
   `godot --headless --path . -s tools/art-gen/generate_character_sprites.gd`.
   It writes one PNG per character to `assets/art/characters/`, as a 4×2 sheet
   (row 0 idle, row 1 moving). Designs follow the art bible:
   - Fayde is an ASCII pixel map: hooded coat to mid-calf, satchel, hood peak as the
     vertical accent, curious face. `fayde_glow.png` marks his hands, lens and
     clasp, and the game tints it (Deepfrost teal by default).
   - Enemies are warped machines drawn as shapes on a neutral base, each with one
     desaturated Prana marker (§5.2). Each keeps its §3.2 silhouette family:
     Drifter is wide and flat, Charger is a tall spike, Cluster is a core with
     orbiters.
   - Bosses are 48×48 and drawn at 2×. The Warped Warden is asymmetric with a
     broken violet spiral (B1). The Vault Sentinel is a vault door with a lock ring
     in reserved teal (B2).
   - Every frame gets a 1 px dark outline, and shading assumes light from the
     top-left.
2. **`PixelCharacter`** (`src/visual/pixel_character.gd`) plays a sheet. It reads
   its parent's `velocity` (and `get_facing_direction()` when the parent has it)
   to pick the row and to flip left or right, so no extra wiring is needed.
   Filtering is Nearest, and the feet sit on the origin.
3. **Data**: `EnemyType.sprite_sheet` and `sprite_pixel_scale`.
   `EnemyInstance.init()` adds the sprite and counter-scales it by `base_scale`, so
   boss pixels stay square (2× on screen). The player scene carries its own
   `PixelCharacter`.
4. **`DebugCircle.hide_body`**: the placeholder now draws only the ground shadow
   and the player's aim and cast beam. A type without a sheet falls back to the
   capsule.
5. Dash afterimages copy the current pixel frame. The combo chain dots float at a
   world height that clears the new sprite at any zoom.

## Alternatives Considered

- **HD-2D illustrated (art bible §10)**: best fidelity, but too costly for a solo
  developer at this stage. Kept in the art bible as a reference.
- **CC0 pixel packs**: none match this cast (warped machines, Fayde's design), and
  mixing styles would break §3.2.
- **8 directions**: 4× the frames. Two facings (right, and mirrored left) are enough
  at this size. Back views can be added later as extra rows without changing the
  API.

## Consequences

- Positive: characters are readable and on-model, all 13 PNGs together are about 14 KB, and any design is one edit and one re-run away.
- Negative: two facings only, and the machine-drawn shapes are simpler than
  hand-painted pixel art. The PNGs are the intended place to hand-polish.
- Bullet telegraph and status tints still modulate the whole enemy node, so the
  sprite flashes with them as the capsule did.
- `IsoCharacter` stays in the scenes (hidden), unused, for a future illustrated
  pipeline.

## Validation

- `tests/unit/character-sprites/pixel_character_test.gd` (13 cases): frame
  selection, sheet layout for every enemy type, whole-number pixel scale, Fayde
  glow sheet size, feet on origin, flip, Nearest filter, ghost frame, and player
  and enemy wiring including boss counter-scale.
- Full suite: 1232 cases, 0 failures.
- Visual evidence: `production/qa/evidence/character-sprites-evidence.md`.
