Question-first workflow is mandatory. Always ask clarifying questions before proposing design. Present 2–4 options with pros/cons before drafting. Show draft before writing to file. Write files only after "yes."

**Why:** Solo dev on Claude Pro; approval gates preserve creative control and conserve context.
**How to apply:** Every file write requires explicit "May I write this to [filepath]?" and a "yes" reply. Audit/report outputs are returned as text, never written to files unless asked.
