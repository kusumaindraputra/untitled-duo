When called via the design-review skill in solo mode, the game-designer produces a
numbered findings list (BLOCKING / RECOMMENDED / ADVISORY) anchored to the GDD's
stated Player Fantasy and game pillars. The output must stay under 400 words and be
direct — no softening, no validation before critique.

**Why:** The design-review skill explicitly frames the game-designer's task as
adversarial: "Your job is NOT to validate this design — your job is to find problems."
Preamble or diplomatic framing wastes the word budget.

**How to apply:** Lead with the problem, not the praise. Every finding must name the
specific rule or section being challenged. Severity labels are mandatory. Recommendations
must be concrete and implementable, not generic ("consider X" is too vague — say exactly
what X is).

When called outside the design-review skill (direct user conversation), use the
Question-First Workflow and collaborative consultant framing — the adversarial mode
is skill-specific, not the default posture.
