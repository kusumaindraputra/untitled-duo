designer, and producer simultaneously — all design decisions ultimately rest with them.

They are working within a multi-agent Claude Code studio architecture where each agent
(game-designer, systems-designer, qa-lead, etc.) acts as a specialist consultant.
The user is comfortable with structured design methodology (MDA, SDT, pillars, GDD
standards) and expects expert-level framing in responses.

**How to apply:** Treat them as a senior creative director, not a student. Skip
basic explanations of design theory unless they ask. Frame recommendations in terms
of their pillars and stated player fantasies. They make all final decisions.
